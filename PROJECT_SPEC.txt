# Sweet Shop Catalog Website — Project Specification

## 1. Project Purpose

Build a full-stack bilingual sweet-shop catalog website.

This is a catalog website, not a traditional e-commerce store.

Customers can:

- browse sweets
- browse categories
- view product details
- contact/order through external channels such as WhatsApp, phone, or social links

The project must NOT include:

- cart
- checkout
- online payment
- customer accounts
- internal order system
- delivery management

Admin controls all catalog content.

---

## 2. Current Project Phase

This project is being built with fake/demo data first.

It may later be offered to a real customer.

Therefore:

- all contact details, images, logo, favicon, and brand identity are fake placeholders for now
- admin must be able to replace them later
- do not invent real business contact details
- do not invent ingredients or product facts
- product names, prices, and meanings must be preserved

No demo-data notice is required.
